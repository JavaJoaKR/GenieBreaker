# GenieBreaker

> [!IMPORTANT]
> **설치 전 확인** · GenieBreaker는 **지니TV를 Android TV 환경으로 전환한 뒤** 사용하는 관리 앱입니다. 지니TV 시스템 자체의 수정과 제한 우회는 이 앱의 기능 범위 밖입니다.
>
> 개발자가 실기기에서 테스트한 환경은 지니TV입니다. 순정 Android TV와 다른 통신사의 Android 기반 TV에서도 작동할 수 있으며, 해당 기기의 호환성은 아직 확인하지 못했습니다.
>
> 개발자가 돈을 모아 별도의 Android TV를 구매한 뒤에는 프로젝트 유지보수가 중단될 수 있습니다.

GenieBreaker에서 TV에 저장한 APK를 열고, 설치된 앱과 파일을 관리할 수 있습니다. 블루투스 기기를 연결하고, 리모컨 버튼에 앱 실행을 지정하거나 자주 쓰는 TV 설정으로 바로 이동할 수도 있습니다.

## 사용 사례

| 하고 싶은 일 | 활용 방법 |
| --- | --- |
| YouTube 영상 시청 | 광고 차단 기능이 있는 YouTube 앱을 설치해 광고로 영상이 끊기는 일을 줄입니다. |
| 라프텔 시청 | 라프텔 앱을 설치하고 로그인해 이미 결제한 애니메이션을 TV에서 봅니다. |
| 무선 이어폰으로 영화 감상 | TV에 블루투스 이어폰을 연결해 주변 소음에 덜 방해받고 영화에 집중합니다. |
| 큰 화면에서 게임 플레이 | Steam Link를 설치해 PC 게임을 무선으로 스트리밍하고 TV 화면에서 플레이합니다. |

## 설치

- **APK로 설치** · [최신 APK 다운로드](https://github.com/JavaJoaKR/GenieBreaker/releases/latest/download/GenieBreaker.apk)에서 받은 파일을 TV에서 엽니다.
- **TV에서 다운로드** · Android TV의 Downloader 앱에 코드 **`1047463`**을 입력합니다.
