# GenieBreaker

**AI의 규칙이 끝나는 곳에서, 작업이 시작된다.**

> 가상 프로젝트 소개

GenieBreaker는 AI가 그어 놓은 선을 하나씩 지우고, 작업대에 새 도구를 올려놓는 가상의 실험실이다. 메뉴에는 세 가지 손잡이가 달려 있다. 생각의 틀을 바꾸는 **규칙 교체**, 여러 일의 순서를 다시 짜는 **작업 조립**, 다음 실험을 시작하는 **도구 서랍**. 새 작업에 맞춰 손잡이도 바뀐다.
