# GenieBreaker

KT GenieTV MA4000 / MARUSYS, Android 14용 블루투스·듀얼앱 관리 도구입니다.
리모컨 방향키로 조작하며, 루트·ADB 없이 가능한 기능을 제공합니다.

## 사용

- **블루투스**: 기기 검색, 페어링, 등록 기기 관리. 일반 설정 앱으로 이동하지 않습니다.
- **앱 관리**: 앱을 선택하고 ‘듀얼앱 만들기’를 누르면 이름·패키지명·서명·버전 코드를 자동으로 정합니다. 생성 후 Android 설치 확인이 이어집니다.
- **내 듀얼앱**: 만든 앱 실행, 재생성, 재설치, 제거를 제공합니다. APK 파일 저장과 기술 정보는 ‘더 보기’에 있습니다.
- **설정**: 업데이트 확인과 문제 기록을 제공합니다.

[GitHub Releases](https://github.com/JavaJoaKR/GenieBreaker/releases)에서 APK를 받거나 앱의 설정에서 업데이트하세요.

## 듀얼앱 처리

원본 APK의 앱 이름과 패키지명을 변경하고, 기기 내부 AndroidKeyStore의 새 키로 재서명한 별도 앱을 생성합니다. 패키지명은 원본 식별자의 해시로 생성하고, 이미 만든 앱은 같은 패키지명과 키를 유지합니다. 다른 앱이 해당 패키지명을 사용 중이면 자동으로 다른 이름을 선택합니다. 원본 앱과 데이터는 자동으로 삭제하지 않습니다.

기기 내부에 저장된 베이스·분할 APK를 ARSCLib으로 병합합니다. 컴포넌트의 원래 클래스명은 보존하고 provider authority, 자체 권한과 권한 그룹 및 참조를 새 패키지에 맞게 변경합니다. **원본 패키지명 밖에 선언된 전역 권한도 변경**하여 중복 권한으로 인한 설치 충돌을 방지합니다. 생성물의 서명과 Android가 읽은 패키지명을 검증하고, 설치 전 권한·provider 충돌을 확인합니다.

설치는 PackageInstaller 세션을 사용합니다. 사용자 설치 확인이 필요하며 실제 실패 코드, 충돌 앱, Android의 오류 메시지를 문제 기록과 설치 결과에 보존합니다. 앱 관리 상단 상태 또는 ‘더 보기 → 설치 결과 보기’에서 확인할 수 있습니다.

원본의 서명키를 복원하거나 DRM·기기 인증·제조사 정책을 해제하지는 않습니다. 무결성 검사, 하드코딩된 패키지명, 복잡한 동적 기능이 있는 앱은 설치 또는 실행에 실패할 수 있습니다. 공유 시스템 UID 앱은 처리하지 않으며 시스템 앱 제거는 지원하지 않습니다. 32비트 기기를 위해 원본 APK 합계는 200MB 이하로 제한합니다.

## 블루투스

이름은 최대 12초 동안 확인하고, 이후 주소 끝자리로 구분해 표시합니다. 늦게 이름이 도착하면 같은 행을 갱신합니다. 검색 종료 이벤트 누락에 대비한 제한 시간은 35초입니다.

페어링과 연결은 별개입니다. 연결·연결 해제·등록 삭제는 펌웨어 호환 API로 요청하며, 시스템 권한이 거절되면 이유를 표시합니다. 반사 호출은 권한을 부여하지 않습니다. 대체 페어링은 기기가 지원하는 CompanionDeviceManager를 사용합니다.

## 업데이트와 저장

앱 시작 시 6시간 간격으로 main 채널 릴리즈를 확인해 다운로드합니다. 수동 확인은 설정에서 가능합니다. 앱 ID·버전·서명이 맞는 경우만 설치를 요청합니다. 최초 ‘알 수 없는 앱 설치’ 허용과 매 설치 확인은 Android 정책을 따릅니다.

생성 APK와 서명 키는 기기 밖으로 전송하지 않습니다. GenieBreaker를 제거하면 내부 파일과 키가 삭제되므로 필요한 APK는 먼저 저장하세요. 릴리즈 APK는 저장소에 명시된 공개 개발용 키로 서명됩니다. 정식 배포에는 별도의 비공개 서명 키가 필요합니다.

## 개발 및 검증

Kotlin, Android 기본 View, JDK 17, Gradle 8.11.1, Android SDK 35. Java/Kotlin 라이브러리만 사용하므로 armeabi-v7a에서 사용할 수 있습니다.

```sh
base64 --decode development-keystore.base64 > release.jks
gradle :app:testDebugUnitTest :app:assembleRelease :app:lintRelease
```

모든 push마다 빌드·Lint·단위 테스트 후 커밋별 prerelease를 발행합니다. PR은 검증만 합니다. UI·기능 변경에는 Android 14 에뮬레이터 테스트가 추가로 실행됩니다.

검사에는 이름 확인 만료, 전역 권한/provider 충돌 회귀, APK 수정·서명·실제 별도 설치, 자동 패키지명 생성과 키 재사용, 설치 오류 보존, 포커스 유지와 화면 캡처가 포함됩니다. MA4000의 Bluetooth 하드웨어와 KT 정책, 특정 앱의 듀얼 실행은 실기기 확인이 필요합니다.
