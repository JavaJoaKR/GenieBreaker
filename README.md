# GenieBreaker

> [!IMPORTANT]
> **설치 전 확인** · GenieBreaker는 지니TV를 Android TV 환경으로 전환한 뒤 사용하는 관리 앱이다. 앱은 지니TV의 시스템을 직접 수정하거나 제한을 우회하지 않는다.
>
> 개발자가 보유한 지니TV에서만 실기기로 검증했다. 순정 Android TV와 다른 통신사의 Android 기반 TV에서도 작동할 수 있으며, 해당 기기의 호환성은 아직 확인하지 않았다.
>
> 개발자가 자금을 모아 별도의 Android TV를 구매한 뒤에는 프로젝트 유지보수가 중단될 수 있다.

GenieBreaker는 Android TV의 APK 설치와 앱·파일 관리를 지원한다. TV에서 블루투스 기기를 연결하고, 리모컨 버튼에 앱 실행이나 시스템 동작을 지정할 수 있다. 자주 사용하는 TV 설정은 바로가기에서 연다.

## 사용 사례

| 사용 목적 | 구성 방법 |
| --- | --- |
| YouTube 영상 시청 | 광고 차단 기능을 제공하는 YouTube 앱을 설치해 시청 중 광고 노출을 줄인다. |
| 라프텔 콘텐츠 시청 | 라프텔 앱을 설치한 뒤 로그인해 이미 결제한 애니메이션을 TV에서 시청한다. |
| 무선 이어폰으로 영화 감상 | 블루투스 이어폰을 TV에 연결해 주변 소음의 영향을 줄이고 영화에 집중한다. |
| TV 화면에서 PC 게임 플레이 | Steam Link를 설치해 PC 게임을 무선으로 스트리밍하고 더 큰 화면에서 플레이한다. |

## 설치

- **설치 프로그램으로 설치** · [Installer.apk](https://github.com/JavaJoaKR/GenieBreaker/raw/refs/heads/main/Installer.apk)를 받거나 TV의 Downloader에 코드 `3523959`를 입력한다. 설치 프로그램을 연 뒤 **최신 버전 설치**를 선택한다.
- **GenieBreaker APK로 직접 설치** · [최신 APK](https://github.com/JavaJoaKR/GenieBreaker/releases/latest/download/GenieBreaker.apk)를 받거나 TV의 Downloader에 코드 `1047463`을 입력한 뒤 APK를 설치한다.
